# Чек-лист проверки мобильной вёрстки

Дата: 2026-07-14
Относится к шагам 1–8 плана [mobile-ui-plan.md](./mobile-ui-plan.md)

---

## Важно понимать перед проверкой

Всё, что сделано в шагах 1–8, проверено **только** типами (`tsc`), линтером, форматтером
и сборкой. Это гарантирует, что код собирается и не содержит ошибок типов, но **ничего
не говорит о том, как оно выглядит**. Вёрстку нужно посмотреть глазами — этот документ
о том, что именно смотреть.

---

## Как запустить

### В браузере на компьютере

```bash
npm run dev
```

Затем F12 → «Toolbar устройства» (`Ctrl+Shift+M`). Контрольные ширины:

| Ширина    | Что это                                                                 |
| --------- | ----------------------------------------------------------------------- |
| **360px** | Типичный Android                                                        |
| **390px** | iPhone 14/15                                                            |
| **414px** | Крупные телефоны                                                        |
| **767px** | Последний пиксель «мобильного» режима                                   |
| **768px** | Первый пиксель «десктопного» режима — панели должны вернуться в колонки |

Отдельно включите эмуляцию касаний (в DevTools: «Toggle device toolbar» уже включает её),
иначе не проверить долгое нажатие и правила `@media (hover: none)`.

### На реальном телефоне (надёжнее)

```bash
npm run dev:mobile
```

Открыть на телефоне: **http://192.168.20.111:5173**

Условия: телефон и компьютер в одной сети Wi-Fi, брандмауэр не блокирует порт 5173.
Обычный `npm run dev` для этого не годится: dev-сервер привязан к `127.0.0.1`
(см. `vite.config.ts`) и по сети не виден — поэтому и добавлена команда `dev:mobile`.

## Что проверять

### Шаг 1–3. Панели

- [ ] На 360px видна верхняя шапка с двумя кнопками: «☰» (категории) и папка (файлы)
- [ ] Кнопка папок **заблокирована и приглушена**, пока категория не выбрана
- [ ] «☰» открывает панель категорий поверх контента, фон затемняется
- [ ] Выбор категории закрывает панель категорий и **сразу открывает панель папок**
- [ ] Выбор файла закрывает панель папок (иначе файл был бы за ней)
- [ ] Панель закрывается: крестиком, кликом по затемнению, `Esc`, свайпом влево
- [ ] Две панели никогда не открыты одновременно
- [ ] Пока панель открыта, фон под ней не прокручивается
- [ ] На 768px и шире панели снова становятся колонками, шапка с кнопками исчезает
- [ ] Низ интерфейса не уезжает под адресную строку браузера (это про `100dvh`)

### Шаг 4. Касания

- [ ] Кнопки правки и удаления в списке файлов **видны без наведения** (на телефоне)
- [ ] Долгое нажатие (~0,5 с) на файле, папке, категории открывает контекстное меню
- [ ] Долгое нажатие на файле **не открывает сам файл** вместе с меню
- [ ] Прокрутка списка пальцем не вызывает меню случайно
- [ ] Мелкие кнопки-иконки удобно попадаются пальцем (44×44)
- [ ] На десктопе правый клик по-прежнему открывает те же меню

### Шаг 5. Порядок элементов

- [ ] В меню категории есть «Move up» / «Move down», на краях списка заблокированы
- [ ] В меню файла есть раздел «Move to folder» со списком других папок
- [ ] Перенос файла в другую папку действительно срабатывает
- [ ] Перетаскивание мышью на десктопе не сломалось
- [ ] **Известное ограничение:** в `LinksView` порядок ссылок и секций пальцем
      изменить нельзя — подшаг 5.3 не делался

### Шаг 6. Контентные вью

- [ ] `LinksView`: поиск занимает отдельную строку, ничего не вылезает за край
- [ ] `PromptsView` и `CommandsView`: таблицы выглядят как **карточки**, а не как
      таблица с горизонтальной прокруткой
- [ ] В карточках нет колонки с порядковым номером, нет колонок Vars/Tags
- [ ] `NoteEditor`: режим «split» на телефоне отсутствует, показана одна панель
- [ ] `NoteEditor`: панель инструментов переносится по строкам, кнопки не обрезаны
- [ ] `PlaybookView`: кнопки шапки на своей строке, ничего не наезжает друг на друга

### Шаг 7. Модальные окна

- [ ] Настройки, Корзина, Импорт/Экспорт открываются **на весь экран**
- [ ] Содержимое прокручивается внутри окна
- [ ] Шапка и кнопки не перекрыты «чёлкой» или полосой жестов (iPhone)

### Шаг 8. Поля ввода

- [ ] **Ключевое (iOS):** при касании любого поля страница **не увеличивается**
- [ ] В полях URL клавиатура показывает «.com», первая буква не становится заглавной
- [ ] В полях поиска клавиша Enter выглядит как «Найти»

### Общее

- [ ] Горизонтальной прокрутки страницы нет **нигде** (проверить на каждом экране)
- [ ] Поворот телефона в альбомную ориентацию не ломает вёрстку
- [ ] Тёмная и светлая темы обе выглядят прилично

## Что делать с найденным

Записывайте кратко: экран, ширина, что не так. Дальше поправим точечно —
все механизмы (хуки, CSS-правила) уже на месте, чинить придётся отдельные места,
а не подход.
