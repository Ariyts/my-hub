Починка терминала в kali
добавить в файл (файл ~/.zshrc) следующие строки:
```
unset LC_ALL
export LANG=C.UTF-8
export LC_CTYPE=C.UTF-8
```

для того что на хосте работала возможность проброса портов на лету

надо в конфиге 

```
sudo nano /etc/ssh/ssh_config
добавить строку в Hosts *
EnableEscapeCommandline yes
```
После это уже в активной сессии можно делать проброс портов локальный
Нажать ~C
в открывшейся ssh> уже можно
```
ssh> -L 3301:127.0.0.1:3301
```
Удалить проброс
```
-KL 3301
```
