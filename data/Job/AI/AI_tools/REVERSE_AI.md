Коротко:

REA (morluto/rea) — это именно то, что сильно помогает в пентесте (особенно black-box / reverse engineering).
Orca (stablyai/orca) — это оркестратор AI-агентов (типа Claude Code, Codex, Cursor CLI и т.д.). Сам по себе он не пентест-инструмент, но очень удобно ускоряет работу, когда ты используешь AI-агентов для анализа кода, написания эксплойтов, автоматизации и т.п.

1. REA — Reverse Engineer Anything
Это CLI + MCP-сервер, который даёт твоему AI-агенту (Claude Code, Cursor, Codex, Grok и др.) мощные инструменты для реверса.
Что умеет (полезно в пентесте):

Нативные бинарники (ELF/PE/Mach-O) через Hopper / Ghidra / IDA → псевдокод, ассемблер, строки, символы, вызовы.
JavaScript / Electron-приложения (включая ASAR).
.NET assemblies.
Android APK (через JADX + Apktool) + работа с устройством через ADB.
Веб-сайты (структура, скрипты, сеть).
Firmware, pcap, WASM, EVM bytecode, Flutter и многое другое.
Всё локально, с доказательствами (evidence) и ограничениями.


2. Orca
Это Agent Development Environment — красивый десктопный (и мобильный) интерфейс, в котором ты запускаешь сразу несколько AI-агентов параллельно.
Что даёт:

Каждый агент работает в своём git-worktree (изолированно).
Можно запустить 3–5 агентов на одну задачу и сравнить результаты.
Поддержка почти всех CLI-агентов (Claude Code, Codex, Cursor, OpenCode, Grok и т.д.).
SSH-worktrees (агенты на удалённой машине).
Мобильное приложение для управления.
Удобный просмотр диффов, аннотации, браузер внутри и т.д.

Как помогает в пентесте:

Быстро параллельно исследовать несколько гипотез («один агент ищет XSS, второй — IDOR, третий — auth bypass»).
Автоматизировать рутину: написание PoC, скриптов, отчётов.
Работать с большим количеством кода/репозиториев без хаоса.

Как использовать:

Скачай с https://onorca.dev или с GitHub Releases (macOS / Windows / Linux).
Установи агентов, которыми пользуешься (Claude Code, Codex и т.д.).
Открой Orca → создай worktree → запусти нужных агентов.

Orca не делает реверс сам — он просто даёт удобную оболочку, чтобы запускать агентов, которые уже умеют работать с REA (или любыми другими инструментами).
Как их комбинировать
Самый мощный сетап:

Ставишь REA → подключаешь к Claude Code / Cursor / Codex.
Запускаешь этих агентов внутри Orca.
В пентесте говоришь агенту: «Используй REA и разбери этот бинарник / APK / Electron-приложение».

Тогда агент сам вызывает нужные инструменты REA через MCP и возвращает тебе результаты с доказательствами.
