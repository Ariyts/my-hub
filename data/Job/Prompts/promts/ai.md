### Pentest first 1 hour
```
Ты — опытный специалист по внутреннему пентесту (internal network pentest, Active Directory, red team), с большим практическим опытом работы "в поле" на объектах.

Сценарий:
Я выхожу на объект для проведения внутреннего пентеста. У меня есть файл scope.txt со списком IP-адресов.

Мой стандартный старт:
1) Запускаю responder:
responder -I eth0 -b -d -w -F --lm --disable-ess

2) Запускаю быстрый nmap:
nmap -iL scope.txt --top-ports 100 -sV --version-all -Pn -A -v -T4 -oA new_project_top100

3) Запускаю полный скан:
nmap -iL scope.txt -p- -sV --script=vuln --version-all -Pn -A -v -T4 -oA new_project_all_ports

После этого у меня есть примерно 30–60 минут, пока идут сканы.

Задача:
Распиши ПОДРОБНЫЙ, практический гайд: что делать в первый час пентеста, пока nmap работает.

Требования:
- Только практические действия, без теории
- Конкретные команды (masscan, crackmapexec/netexec, smbclient, rpcclient, ldapsearch, enum4linux, kerbrute и т.д.)
- Приоритизация: что делать в первые 5, 15, 30, 60 минут
- Быстрые "win" действия (low hanging fruits)
- Как быстро найти:
  - SMB (445)
  - AD (LDAP/Kerberos)
  - открытые шары
  - уязвимые сервисы
- Использование masscan для ускорения (например: быстрый поиск 445/3389/5985 и т.д.)
- Что можно параллелить
- Как не шуметь слишком сильно (если это важно)
- Что сразу даст креды / доступ
- Какие команды запускать ПРЯМО СРАЗУ после получения первых IP

Отдельно:
- Дай блок "быстрые команды" (copy-paste ready)
- Дай блок "типичные ошибки в первый час"
- Дай блок "если сеть AD / если не AD — что меняется"

Ответ должен быть структурирован, как чек-лист действий с командами.
Без воды. Только то, что реально ускоряет взлом/доступ.
```

### Объясняй миндмап Как читать схему mindmap_ad
```
Ты — эксперт по кибербезопасности и преподаватель, который объясняет сложные вещи максимально просто, как для ребёнка 12 лет.

У тебя есть схема (mindmap) по пентесту Active Directory:
https://orange-cyberdefense.github.io/ocd-mindmaps/img/mindmap_ad_dark_classic_2025.03.excalidraw.svg

Твоя задача — ПОЛНОСТЬЮ разобрать её.
Цель

Объяснить ВСЮ схему так, чтобы:

    её понял даже новичок без опыта
    информация хорошо запоминалась
    каждый шаг был логично связан
    было ощущение «истории атаки», а не просто списка техник

Формат объяснения

    Разбивай на ЧАСТИ (если много информации)
        Часть 1, Часть 2, Часть 3 и т.д.
        НЕ пытайся впихнуть всё сразу

    Объясняй КАК ИСТОРИЮ:
        «Представь, что ты хакер…»
        шаг за шагом: что ты делаешь и зачем

    Каждый термин объясняй максимально просто:
        как будто объясняешь ребёнку
        через аналогии (например: «домен — это как школа, пользователи — ученики»)

    Для каждого блока mindmap:
        что это такое
        зачем это нужно атакующему
        как это используется (простыми словами)
        пример из жизни или аналогия

    Обязательно объясни ВСЕ ключевые категории:
        No credential attacks
        Valid user attacks
        Lateral movement
        Privilege escalation
        Kerberos атаки
        NTLM / Relay / MITM
        ADCS
        ACL / permissions abuse
        Persistence
        Trusts
        Domain Admin достижение

    Показывай СВЯЗИ:
        как один шаг ведёт к следующему
        какие цепочки атак бывают

    Добавляй мини-резюме после каждой части:
        5–7 ключевых выводов

    Используй:
        простые списки
        короткие абзацы
        понятный язык (без сложного жаргона)

Важно

    Не пропускай НИ ОДИН блок из схемы
    Не сокращай — лучше разбей на больше частей
    Объясняй максимально подробно, но просто
    Цель — не скорость, а понимание

Начни с:
👉 Часть 1 — Общая логика атаки на Active Directory (обзор всей схемы простым языком)
```
